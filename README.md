# Mimikatz-Bypass

## Description

This project provides techniques and tools for running Mimikatz while bypassing Windows Defender protection on Windows 10 systems. Mimikatz is a powerful post-exploitation tool used for credential dumping and lateral movement in security assessments and penetration testing scenarios.

## Overview

Mimikatz-Bypass enables security professionals and penetration testers to execute Mimikatz on Windows 10 systems with Windows Defender enabled. This toolkit includes various evasion techniques to help bypass Windows Defender detection mechanisms while maintaining the functionality of Mimikatz for authorized security testing.

## Requirements

- **Windows 10** operating system
- **Administrator PowerShell** access (required for execution)
- Windows Defender (for testing evasion techniques)

## Usage

### Prerequisites
Ensure you have administrator-level privileges on your PowerShell session:

```powershell
# Run PowerShell as Administrator
# Right-click PowerShell and select "Run as administrator"
```

### Execution

1. Open an **Administrator PowerShell** session
2. Navigate to the project directory
3. Execute the bypass techniques according to the documentation in this repository
